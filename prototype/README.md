# 要件確認用プロトタイプ

技術スタックを決める前に、要件定義の内容を画面で確認するための簡易プロトタイプです。
HTML・CSS・JavaScript のみで作成しています。

## 実装している要件

| No | 機能 |
|---|---|
| F-01 | 期間(開始日・締め日)の設定 |
| F-02 | 上限金額の設定・変更 |
| F-03 | 支出(品名・金額・購入日)の登録 |
| F-04 | 支出の一覧表示(購入日の新しい順) |
| F-05 | 支出の編集・削除 |
| F-06 | 予算状況(上限・使用済み・残り・使用率)の表示 |
| F-07 | 使用率に応じた背景色の切り替え(80%以上で薄い赤、100%超で濃い赤) |

複数の期間を作成した場合は、画面上部のプルダウンで期間を切り替えられます。

## 注意

- データはブラウザの localStorage に保存しています。本番の技術スタック(保存方法)とは関係ありません
- 画面下部の「全データを消去」で保存データをリセットできます
